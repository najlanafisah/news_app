# News App

A Flutter-based mobile application for browsing news articles and viewing their details through a simple and user-friendly interface.

## Features

- Browse news articles
- View news article details
- Navigate between application screens
- Fetch news data from an external API

## Tech Stack

- **Flutter**: Cross-platform application development
- **Dart**: Programming language
- **GetX**: State management and navigation
- **HTTP**: API requests
- **Flutter Dotenv**: Environment variable configuration

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- News API credentials, if required

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/news_app.git
   cd news_app
   ```

2. Install dependencies:

   ```bash
   flutter pub get
   ```

3. Configure the required environment variables in the `.env` file.

4. Run the application:

   ```bash
   flutter run
   ```
